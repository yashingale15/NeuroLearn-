# 🧠 NeuroLearn+

### AI-Powered Personalized Multimodal Learning Assistant

> **NeuroLearn+** is an AI-assisted educational platform designed to provide **inclusive, adaptive, and personalized learning experiences** based on learner engagement and performance.

---

## 🚀 Features

| Feature | Description |
|---|---|
| 🧩 **Autism Learning Module** | Currently implemented learning experience focused on Autism |
| 🎯 **Personalized Learning** | Learning experience designed around individual learner needs |
| 📚 **Multimodal Learning** | Supports text, audio, visual and interactive learning |
| 🎮 **Interactive Activities** | Engaging activities to improve learner participation |
| 📊 **Engagement Tracking** | Tracks learning interaction and performance |
| 🤖 **AI/ML Personalization** | AI-based adaptive learning planned |
| 🏗️ **Modular Architecture** | Designed to support additional learning modules |

> **Current Implementation:** The project currently contains the **Autism module**. Dyslexia and ADHD are planned for future development.

## ⚙️ Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/yashingale15/NeuroLearn-.git
cd NeuroLearn-
```

### 2️⃣ Install Dependencies

#### Backend

```bash
cd backend
npm install
```

#### Frontend

Open another terminal:

```bash
cd neurolearn-frontend
npm install
```

---

## ▶️ Run the Application

### Backend

Navigate to the backend:

```bash
cd backend
```

Start the server:

```bash
npm start
```

If the project uses a development script:

```bash
npm run dev
```

### Frontend

Open another terminal:

```bash
cd neurolearn-frontend
```

Start the frontend:

```bash
npm start
```

For Vite-based projects:

```bash
npm run dev
```

After starting the frontend, open the URL shown in your terminal.

Usually:

```text
http://localhost:5173
```
